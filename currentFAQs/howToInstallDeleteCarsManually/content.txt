# How to install / delete cars manually

---

# Wondering how to install and/or delete cars manually directly in the game folder, follow this guide!

---

# What this FAQ is for:
> If you are having issues with a specific car, please **ensure you delete any of its files before manually reinstalling it**. 
> If you are simply here to manually install a car, then follow the second part of the guide.

---

# How to delete car files:
> All the cars you have installed will be found by going to: <#1322235675239645184> → `content` → `cars`. 
> 
> Here you can find the car you need to delete → right-click on it, then click `delete`.
> 
> Please also delete the car folder/zip from anywhere else it may be, eg your downloads folder. This way you can start from a clean slate for the next step.

---

# How to manually install cars:
> **Step 1: Download & Install 7zip: (*do NOT use WinRAR*)**
> 1. Open https://www.7-zip.org/
> 2. Click "Download"
> 3. Double-click the downloaded exe file
> 4. Follow the prompts to complete the install
[attachment: 1.png]

---

> **Step 2: Download the car file:**
> Head over to our [**Content Delivery Network**](<https://cdn.nohesi.gg/cars/>) and find the cars you need to download.
> 
> **Step 3: Install the car:**
> 1. Right click the downloaded ZIP file -> click `7zip` -> `Open Archive`
> -# Windows 11 users will need to click `show more options` before they can find 7zip.
> 2. Drag & drop the car folder into your car's folder (<#1322235675239645184> → Content → Cars)
> 
> **Step 4: **
> Make sure you restart Content Manager by closing it and reopening it.
