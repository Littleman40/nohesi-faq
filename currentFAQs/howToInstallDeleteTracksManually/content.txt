# How to install a track manually

---

## Step 1
**Download and Install 7zip. (*do NOT use WinRAR*)**
> 1. Open https://www.7-zip.org/
> 2. Click "Download"
> 3. Double-click the downloaded exe file
> 4. Follow the prompts to complete the install
[attachment: 1.png]

---

## Step 2
**Download the track file:**
> * [Shuto Revival Project Beta](<https://discord.com/channels/964645662866173972/1322236089083105343>)
> * [110 V1 - Public](<https://bcdn.nohesi.gg/maps/nohesi_110_public.7z>)
> * [110 Chinatown Expansion - Tier 3](<https://cdn.nohesi.gg/maps/nohesi_110.7z>)
> * [110 V2 - Tier 3](<https://cdn.nohesi.gg/maps/nohesi_110_v2.7z>)
> * Any other map: https://cdn.nohesi.gg/maps/

---

## Step 3
**Install the track**
> 1. Right-click the track zip file you downloaded
> 2. Press "show more options" -> 7zip -> open archive
> 3. Depends if you see a `content` / `apps` folder or the track name, do the following:
>    * If you see `content` and/or `apps`, drag and drop both of these folders into your root folder: <#1322235675239645184> 
>    * If you see the track name, drag and drop it into your track folder, found at: `assettocorsa\content\tracks`
